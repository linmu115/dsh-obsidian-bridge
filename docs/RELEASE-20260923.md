# 生命周期与动态组合修整

运行环境：**DSH 0.1.5-rc.2 实例 / web profile**。

- Bridge 的基础连接、Vault 绑定与 CLI 无需安装 Core / Maintenance；引用子功能在 Core 服务出现时接入，移除时撤销，恢复后重新接入。
- 可选 Maintenance 身份冲突按其依赖作用域暂停通道；移除或更换提供方后重新核验恢复。稳定身份和 Vault 绑定不自动改写。
- Vault 通道替换与最终卸载等待旧通道清理，避免新旧通道交叠。
- 客户端晚到的刷新和初始化结果不会复活已卸载的服务；远程描述符只释放一次。

完整源码测试、类型检查与无 Core 发行包加载纳入本轮验证。实际安装状态见交付回执；没有以单元测试替代 UI 或真实运行中热替换验收。

升级：正常停止 DSH，备份配置与插件目录后安装发行包，再按原方式启动。保留原 Vault 绑定、身份存储与 CLI 回执，不需要重新绑定。
